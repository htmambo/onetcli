> 整理时间：2026-04-21
> 排除 sync_server 相关代码

## 基准目录

项目运行时使用两个不同的基准目录：

| 目录 | 用途 | Linux | macOS | Windows |
|------|------|-------|-------|---------|
| `get_config_dir()` | 应用配置数据 | `~/.config/one-hub/` | `~/.config/one-hub/` | `%APPDATA%\one-hub\` |
| `get_data_dir()` | 敏感认证/加密数据 | `~/.local/share/one-hub/` | `~/Library/Application Support/one-hub/` | `%LOCALAPPDATA%\one-hub\` |

## config_dir：~/.config/one-hub/

### 1. 主数据库 (SQLite)
| 属性 | 内容 |
|---|---|
| **文件** | `one-hub.db` |
| **数据类型** | `rusqlite::Connection`，表：connections、workspaces、certificates、key_values、pending_cloud_deletions |
| **读取时机** | 应用启动时由 `StorageManager` 初始化加载 |
| **写入时机** | 用户创建/编辑/删除连接、工作区、证书时同步写入 |

### 2. 标签页状态 (Tab State)
| 属性 | 内容 |
|---|---|
| **文件** | `tab_state.json` |
| **数据类型** | `TabContainerState` (serde JSON) |
| **读取时机** | 应用启动时 |
| **写入时机** | 用户操作标签页后延迟 5 秒同步写入（5秒防抖） |

### 3. 连接恢复快照 (Connection Restore)
| 属性 | 内容 |
|---|---|
| **文件** | `connection_restore_state.json` |
| **数据类型** | `ConnectionRestoreSnapshot` → `ConnectionRestoreItem` 列表，含 kind: LocalTerminal/SshTerminal/Sftp/Database/DatabaseWorkspace/Redis/RedisWorkspace/MongoDb/MongoDbWorkspace 及对应状态 |
| **读取时机** | 应用启动时 |
| **写入时机** | 与 tab_state.json 同时保存（5秒防抖后并发写入） |

### 4. 主题状态 (Theme State)
| 属性 | 内容 |
|---|---|
| **文件** | `theme_state.json` |
| **数据类型** | `ThemeState { theme: SharedString, scrollbar_show: Option<ScrollbarShow> }` |
| **读取时机** | 应用初始化时，包含从旧路径 `target/state.json` 的迁移逻辑 |
| **写入时机** | 用户切换主题时触发 `SwitchTheme` action |

### 5. 服务器监控偏好 (Server Monitor Preferences)
| 属性 | 内容 |
|---|---|
| **文件** | `server-monitor.json` |
| **数据类型** | `ServerMonitorPreferences { enabled_connections: BTreeMap<String, bool> }` |
| **读取时机** | 启动时加载服务器监控面板 |
| **写入时机** | 用户在连接列表中切换监控开关时 |

### 6. 演示数据库 (Demo Database)
| 属性 | 内容 |
|---|---|
| **文件** | `demo_orders.db` |
| **数据类型** | SQLite 数据库文件，内置 SQL 脚本 `demo_orders.sql` |
| **读取时机** | 启动时检查连接数是否为 0（首次使用） |
| **写入时机** | 仅首次创建，创建后不修改 |

### 7. 缓存目录 (Cache)
| 属性 | 内容 |
|---|---|
| **目录** | `cache/` |
| **子路径** | `{cache_dir}/{database_type}/{host_port}/{node_id}.json` |
| **数据类型** | `CachedNode { node: DbNode, cached_at: i64, ttl_millis: u64 }` |
| **读取时机** | 按需查询数据库元数据时 |
| **写入时机** | 首次查询到节点时异步写入 JSON |
| **TTL** | 默认 120 秒 |
| **清理机制** | 每 5 分钟后台任务清理过期文件 |

### 8. 元数据缓存 (Metadata Cache)
| 属性 | 内容 |
|---|---|
| **目录** | `cache/metadata/` |
| **子路径** | `{cache_dir}/metadata/{connection_id}/{database}/{schema}/{object_name}_{entry_type}.json` |
| **数据类型** | `CachedEntry<CachedMetadataEntry>`，枚举含：Databases/Schemas/Tables/Views/Columns/Indexes/ForeignKeys/Functions/Procedures/Triggers/Sequences/TableDDL |
| **读取时机** | 按需查询表/列等元数据时 |
| **写入时机** | 查询到元数据时写穿到磁盘（memory + disk） |
| **TTL 分层** | Connection(5min)、Database(3min)、Table(2min)、Detail(1min) |
| **清理机制** | 共享 NodeCache 的每 5 分钟清理任务 |

### 9. 查询存储 (Queries Directory)
| 属性 | 内容 |
|---|---|
| **目录** | `queries/` |
| **数据类型** | 用户保存的 SQL 查询文件 |
| **读取时机** | 按需读取保存的查询 |
| **写入时机** | 用户保存查询时 |

### 10. 终端主题 (Terminal Theme Override)
| 属性 | 内容 |
|---|---|
| **目录** | `themes/` |
| **数据类型** | JSON 格式主题定义 |
| **读取时机** | 加载主题时 |
| **写入时机** | 用户自定义主题时 |

## data_dir：~/.local/share/one-hub/（敏感数据）

### 11. 认证令牌 (Auth Tokens)
| 属性 | 内容 |
|---|---|
| **文件** | `auth.json` |
| **数据类型** | `serde_json::Value` 含 `access_token`、`refresh_token`、`user_id`、`expires_at` |
| **读取时机** | 启动时恢复会话 |
| **写入时机** | 登录时、刷新 token 时 |

### 12. 密钥存储 (Key Storage)
| 属性 | 内容 |
|---|---|
| **文件** | `key_storage` |
| **数据类型** | 原始字节（AES-256-GCM 加密后的主密钥） |
| **读取时机** | 应用启动时首次需要解密密码时 |
| **写入时机** | 用户首次设置主密码时 |
| **密钥派生** | HKDF，基于 CPU 架构 + hostname + username，机器绑定 |

### 13. 密钥验证文件 (Key Verification)
| 属性 | 内容 |
|---|---|
| **文件** | `key_verification` |
| **数据类型** | V1: 明文测试字符串；V2: `ENC:V2:base64(salt + nonce + ciphertext)` |
| **读取时机** | 解密密码前验证主密钥是否正确 |
| **写入时机** | 设置主密码时同时写入 |

## 其他目录

### 14. 下载目录
| 属性 | 内容 |
|---|---|
| **路径** | 系统下载目录（`dirs::download_dir()`） |
| **用途** | 数据库/SFTP 导出/下载文件的目标位置 |
| **数据类型** | 无结构，由用户交互触发文件写入 |

### 15. 远程监控 Helper 脚本
| 属性 | 内容 |
|---|---|
| **目录** | `$HOME/.onetcli-monitor` |
| **文件** | `collect.sh` |
| **用途** | 远程服务器监控数据采集脚本 |

## 不落盘的数据

| 模块 | 数据类型 | 说明 |
|------|---------|------|
| 终端命令历史 | `VecDeque` | 纯内存缓存，不写入磁盘 |
| 临时文件 | 系统临时目录 | 非核心存储 |
