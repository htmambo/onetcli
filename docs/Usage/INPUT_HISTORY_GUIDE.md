# AI 输入框历史记录（↑ / ↓ / Ctrl-R）

> **状态**: ✅ 已发布（2026-09-05）
> **适用版本**: omnihub main 分支
> **适用面板**: ChatDB AI 输入框、AI Chat Panel（SSH/Serial 终端侧栏）

## 功能概述

AI 输入框支持类似 Claude Code / 终端 shell 的"上下箭头历史记录"：

- 按 **↑**：从最近提交的消息开始，逐条往更早的提交回溯
- 按 **↓**：从当前位置往最近的方向回退，最后恢复未提交草稿
- 按 **Ctrl-R**：进入反向搜索（按查询子串循环匹配）
- 按 **Esc**：清空输入框 + 复位临时记录（仅在浏览态生效）

跨会话视图：最近 50 条跨会话 user 消息会自动加载到全局历史区，浏览时无差别访问。

## 使用方法

### 基本操作

| 操作 | 效果 |
|---|---|
| 输入框为空，按 ↑ | 显示最近一条提交 |
| 继续按 ↑ | 依次显示更早的提交（cursor 递增） |
| 在历史中间按 ↑ | 继续往更早走 |
| 在最旧一条按 ↑ | 无反应（已到边界） |
| 在历史中间按 ↓ | 往最近方向回退 |
| 在最新一条按 ↓ | 恢复未提交草稿（若有）或清空输入框 |
| 浏览时编辑 | 修改的是临时副本，**不**立即影响 history |

### 浏览中编辑

| 用户操作 | 行为 |
|---|---|
| 浏览 history[i] 时输入文字 | 输入框 = history[i] 的临时副本（history[i] 本身不变） |
| 切换到 history[j]（↑/↓） | 临时副本与 history[i] 比较：不同且非空 → 覆盖 history[i]；相同 → 不动；空 → history[i] 保留 |
| 在浏览态提交（按 Enter） | 提交内容压入 history[0]（最新），原 history 整体后移 |
| 浏览态空内容时按 Enter | **不允许提交**（无反应） |

### Esc 行为

按 Esc 在三种状态下的不同效果：

| 当前状态 | Esc 效果 |
|---|---|
| 浏览态 | 清空输入框 + 复位（cursor=None, draft=None），history 不变 |
| 编辑态（输入但未提交） | **不接管**，由默认 Escape 行为处理（让原有清空/退出逻辑生效） |
| IME 组合输入 | **不接管**，让 IME 处理 |
| 搜索态（Ctrl-R 之后） | **不接管**，让搜索逻辑处理 |

## 跨会话历史

启动时自动异步加载最近 50 条跨会话 user 消息，喂入 history 的"全局段"。浏览时本地段（local）和全局段（global）按时间倒序合并呈现：

```
history[0]            = 最近一条本地提交
history[1..local_len)  = 较早的本地提交
history[local_len..)  = 跨会话全局最近 50 条
```

数据库查询在后台线程（`smol::unblock`）执行，不阻塞 UI。

## 状态机速查

```
         [编辑态 cursor=None]
              │ 按 ↑
              │ (draft 压栈)
              ▼
         [浏览态 cursor=Some(i)]
            │      │ 按 ↑  (i+1)
            │      ▼
            │   [浏览态 cursor=Some(i+1)]
            │      │ 持续按 ↑ 直到 i == len-1 → Noop
            │      │
            │      │ 按 ↓  (i-1)
            │      ▼
            │   [浏览态 cursor=Some(i-1)]
            │      │ 持续按 ↓ 直到 i == 0 → 退出浏览 → 恢复 draft / 清空
            │
            │ 按 Enter (内容非空)
            ▼
         [提交 → 压入 history[0] → cursor=None]
```

## 边界条件

| 场景 | 行为 |
|---|---|
| IME 拼音组合中按 ↑/↓ | 不接管（让 IME 处理候选） |
| 输入框有选区时按 ↑/↓ | fallthrough 到默认 MoveUp/MoveDown（光标按选区扩展） |
| 光标不在第一行最顶时按 ↑ | fallthrough（光标先上移一行） |
| 光标不在最后行最底时按 ↓ | fallthrough（光标先下移一行） |
| history 为空时按 ↑ | Noop（fallthrough） |
| 搜索态（Ctrl-R 后）按 ↑/↓ | 切换搜索 matches（不按 history 方向） |

## 与终端历史记录的关系

| 维度 | 终端 `HistoryPromptState` | AI 输入框 `InputHistory` |
|---|---|---|
| 范围 | 单终端命令 | 跨会话 + 当前会话 |
| 单/多行 | 单行 | 多行 |
| 方向 | ↑→旧 ↓→新 | ↑→旧 ↓→新（一致） |
| Ctrl-R | 有 | 有 |
| 草稿机制 | 有 | 有 |
| 删除语义 | 无 | 无（按设计） |

实现**未**直接复用 `HistoryPromptState`：终端是单行 + 单宿主；AI 输入框是多行 + 三宿主，需要独立状态机。

## 已知限制

- 搜索态 UI 反馈未实现（按 Ctrl-R 后无视觉提示，仅 state 已切换；M7 UI 后续轮次补）
- 历史条数无上限（按当前 usage 应足够；如需可后续加 cap）
- 不支持手动删除某条历史（按用户确认：清空仅清显示，不动 history；删除路径未实现）
- 会话切换（ChatPanel::start_new_session / load_session）会清空本地段，保留全局段

## 验证清单（M11 用户验收）

- [ ] 编辑态输入"hello"，按 ↑ → 显示最近一条提交（draft 保留）
- [ ] 继续按 ↑ → 显示更早一条
- [ ] 到最旧一条再按 ↑ → 无反应
- [ ] 按 ↓ 回到最近一条
- [ ] 在最新一条按 ↓ → 输入框恢复"hello"
- [ ] 浏览 history[0] 时输入"hello modified"，按 ↑ → history[0] 被覆盖为"hello modified"，history[1] 显示原 history[0]
- [ ] 浏览 history[0] 时清空输入框，按 ↑ → history[0] 保留原值
- [ ] 浏览 history[0] 时清空输入框，按 Enter → 无反应（不提交）
- [ ] 浏览 history[0] 时修改后按 Enter → 提交内容压入 history[0]，原 history[0] 移至 history[1]
- [ ] 浏览时按 Esc → 输入框清空，history 不变
- [ ] 编辑态按 Esc → 不接管（保持原有 Escape 行为）
- [ ] 全局历史在 ChatPanel 重启后仍可见
- [ ] SSH 终端、Serial 表单等其他 InputState 用户按 ↑/↓ 不受影响

## 故障排查

| 现象 | 可能原因 | 排查路径 |
|---|---|---|
| 按 ↑/↓ 无反应 | focus 不在 AI 输入框 | 确认 cursor 在 AI 输入框内（点击输入框聚焦） |
| 仅本地历史可见 | 全局历史异步加载未完成 | 等待几秒；或检查日志中 `load_global_input_history` 错误 |
| 浏览态按 Enter 无反应 | 输入框为空 | 浏览态空内容不允许提交（按用户设计） |
| ↑/↓ 仍触发光标移动 | 光标不在第一行/最末行 | 把光标移到第一行最顶/最末行最底再试 |
| Esc 清空了正在编辑的内容 | 用户处于浏览态时按了 Esc | 这是预期行为；按 ↓ 恢复草稿（如有） |
